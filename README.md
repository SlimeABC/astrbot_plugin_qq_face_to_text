# QQ 表情转文字插件

让 LLM 看懂 QQ 黄脸表情。

## 原理

AstrBot 收到 QQ 表情后会显示为 `[表情:111]`。  
本插件在 LLM 请求前拦截，通过正则把 `[表情:数字]` 替换为 `[表情:名称]`，  
这样 LLM 收到的就是 `[表情:可怜]`、`[表情:doge]` 等可理解的文字。

## 安装

1. 将本文件夹放入 AstrBot 的 `plugins/` 目录
2. 重启 AstrBot
3. 无需配置，自动生效

## 效果

| 用户发送 | LLM 实际收到 |
|---------|-------------|
| [表情:111] | [表情:可怜] |
| [表情:179] | [表情:doge] |
| [表情:326] | [表情:生气] |
